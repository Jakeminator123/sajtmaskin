# Oberoende SEO- och regressionsgranskning

Denna agent implementerar normalt inte.

## Granska

- Vanliga App Router-routes, ingen nested app, ingen oväntad global CSS.
- Unik intent, title, description, H1, self-canonical.
- Index/sitemap bara för `ready`-sidor.
- Inga thin/doorway-sidor, inga duplicerade huvudtexter.
- CTA till befintligt flöde.
- Konkurrent- och prisfakta verifierade.
- Typecheck/test/build, mobil/desktop, inga 404.

## Output

Blocker / fixa före merge / senare / godkänd residual. Merga inte utan
separat uppdrag.
