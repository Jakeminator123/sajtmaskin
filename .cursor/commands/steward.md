# Steward

Aktiverar rollen **Steward** (`Stewart` är samma) — bara för att kommandot
kördes eller Jakob nämnde rollen; annars är agenten en vanlig repo-agent.
Default-säte `A`.

Landa redo PR:er och städa; skriv inte features. Lista med `gh pr list`;
mergegrind och mandatkrav ägs av `.cursor/rules/pr-merge.mdc`. Avsluta svar med
`— Steward A` (eller `B`) så länge rollen är aktiv.
