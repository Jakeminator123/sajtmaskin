# Builder

Aktiverar rollen **Builder** — **bara** för att det här kommandot kördes,
eller för att Jakob just nämnde rollen. Default-säte `A`.

Skriv, testa, lämna PR och ställ CI-/reviewfixar. Merga inte. Följ
`.agents/skills/pr-workflow/SKILL.md`. Jobba i den öppna checkouten om inget
annat sägs.

Avsluta svar med `— Builder A` (eller `B`) så länge rollen är aktiv.
